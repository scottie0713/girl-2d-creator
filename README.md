# 2D Girl Creator (3D素体ポーズから2D嘘パース線画・下地生成ツール)

3D素体（マネキン）でポーズと構図を決め、イラスト特有の「嘘パース」や曲線をブラウザ上でベクターとして直感的に整え、**部位別レイヤー付きPSD（Clip Studio Paint互換）**やSVGとして書き出せるクリエイティブWebツールです。

---

## ✨ 主な特徴と機能

### 1. Step 1: 3Dポージング画面 (WebGL / Three.js)
- **女性素体マネキン**: 髪・目・鼻・口をあえて排除した、プレーンでなめらかな女性プロポーション素体。
- **画角・パース調整**: FOVスライダー（望遠〜広角）やアオリ（下から）、俯瞰（上から）、正面、斜め45°プリセット。
- **ポーズプリセット**:
  - S字コントラポスト（王道の立ち姿）
  - 腰に手を当てる（アクティブ）
  - おしとやか（手を前で重ねる）
  - 振り向き（背中・見返り美人）
  - ジャンプ・躍動
  - 座りポーズ
- **部位別FK微調整**: 首、胸、腰、腕、脚の角度をスライダーで個別微調整可能。

### 2. 3D → 2Dベクター＆下地塗り 抽出エンジン
- **幾何学的シルエット抽出**: 3Dポリゴンの法線と視線ベクトルの幾何計算により、外形輪郭線および稜線をベクター（ベジエ曲線）として抽出。
- **素体の内側塗りつぶし**: 素体の各パーツ（頭、胸、腹、腕、脚など）の内側を閉じたポリゴンとして検出し、肌色の下地塗りレイヤーとして自動生成。
- **深度ソート**: カメラからの前後関係を自動判定し、手前にあるパーツが上に重なるよう配置。

### 3. Step 2: 2Dベクター＆「嘘パース」調整画面 (Paper.js)
- **アンカーポイント＆ハンドル変形**: 輪郭の丸み、顎のシャープさ、手足の曲線をベクターのまま直感調整。
- **ゆがみブラシ (Liquify Push)**: ブラシでなぞって輪郭を押し込み・引き出し（イラストレーター御用達の整形機能）。
- **パペットワープ / 誇張変形**: 手前にある部位（突き出した手や足など）を拡大して迫力あるパースを作成。
- **線の太さ調整**: 主線の太さをスライダーで調整。
- **顔の十字アタリ線ガイド**: 3D素体に顔がなくても、頭部の上に目・鼻・口の配置目安となるガイド十字線をワンクリックで表示。
- **部位別レイヤー管理**: 頭部、胸部、腕、脚ごとの「線画」「下地塗り」の表示/非表示（👁）、ロック（🔒）、不透明度、色変更。

### 4. 部位別レイヤー保存（エクスポート）
- **PSD形式（Clip Studio Paint / Photoshop互換）**:
  - 部位ごとの「線画レイヤー」「下地塗りレイヤー」がそのまま分かれたPSDファイルを出力。
  - **Clip Studio Paintで開けば、すぐに髪の毛、顔のパーツ（目・鼻・口）、服を描き足すことができます！**
- **SVG形式**: IllustratorやInkscape等で編集可能なベクターファイル。
- **透過PNG連番 (ZIP)**: 各部位ごとの透過PNG画像アーカイブ。
- **統合PNG**: 1枚の完成透過PNG。

## 🚀 起動方法 (Docker)

Dockerコンテナ上で環境構築されており、ホスト側の環境を汚さずに1コマンドで起動できます。

```bash
# 1. コンテナのビルドと起動
docker compose up --build

# バックグラウンドで起動する場合:
# docker compose up -d --build
```

ブラウザで下記にアクセスしてください：
```text
http://localhost:5173
```

停止する場合:
```bash
docker compose down
```
